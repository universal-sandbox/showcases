# Universal Sandbox Showcases

This repository contains details about various showcases built using the Universal Sandbox.

## Showcases

### Broken Links Checker

Tools that crawl websites to identify broken links using the Universal Sandbox browser environment.

| Implementation | Description |
|----------------|-------------|
| [Python](./broken-links-checker/README.md) | Python-based broken links checker using Playwright |
| [Node.js](./broken-links-checker-node/README.md) | Node.js-based broken links checker with CLI options |
